# 地方时时钟 · Local Time

面向高中地理学习者的现代 Android 地理时间实验室。

## 核心体验
- GPS / 手动经纬度
- 区时、教材意义上的地方时、平均太阳时、视太阳时分层展示
- 太阳高度、方位、太阳轨迹、日出日落
- 日期与时间模拟
- 地理题计算过程
- 直射点、昼夜、晨昏线、极区状态
- Material 3、深浅主题、低动态模式
- 核心数学离线运行

## 工程原则
首屏不初始化天气、网络、复杂地理数据；动画只消费已经计算好的状态，不在每帧触发网络或数据库操作。核心算法位于纯 Kotlin 包，便于 JVM 单测。

## 构建
GitHub Actions 使用 JDK 17、Android SDK 和 Gradle Wrapper。正式发布时使用 GitHub Secrets 注入签名材料，仓库绝不保存 keystore。
